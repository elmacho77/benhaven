Accessibility

This website is built to be readable, keyboard usable, and clear about emergencies.

Benhaven aims to meet WCAG 2.2 Level AA on this website. If something blocks you, tell the department and someone will work on it.

What you can use

  • A skip link at the top of each page moves keyboard focus to the main content.
  • Pages use landmarks: header, navigation, main, and footer. Navigation has accessible names.
  • The menu button shows Menu or Close, and it can be dismissed with the Escape key.
  • Focus is visible. Color is not the only way to see the current page or an error.
  • Body text is large. The typeface is Inter when your device has it, and a system font otherwise.
  • Form fields have visible labels. Required fields are marked in text, not by color alone.
  • Phone numbers are links, so a phone can dial them.
  • Alert banners include the words “Public notice” or “Burn ban,” not color by itself.

Known limits

  • Map links open Google Maps or OpenStreetMap. Those sites control their own accessibility.
  • The burn-ban and emergency banners are inserted by JavaScript from the configuration file. If JavaScript is off, call 919-499-9511 to ask whether a notice is in effect. A note at the top of each page says this.
  • Station photographs are reference images. Text in those photos, including a small copyright line from the source image, may be hard to read. The address is also written beside each photo.

Report a barrier

Call 919-499-9511 or email info@bes13.com. Say which page you were on and what you were trying to do. For an emergency, dial 911 rather than using this page.
