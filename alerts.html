Alerts

Website notices appear in a banner above the header. If you do not see one, nothing is posted.

Nothing is posted right now

If a red emergency banner or a gold burn-ban banner is not showing above the site header, the department has not posted a website alert.

How banners work

Two switches live in one configuration file, assets/js/config.js, in the website project.

  • Emergency banner. Set emergencyBanner.active to true and write a plain-text message. The banner is red and shows on every page. It is for a short public notice the department wants seen immediately.
  • Burn-ban banner. Set burnBan.active to true and edit the message. The banner is gold. The same switch drives the home page, this page, and the burn permits page.

Both switches are off by default. To post a notice, edit the file, publish it on the main branch of the website, and set active back to false when the notice ends. Do not put private information, patient details, or member names in a banner.

A banner on this website does not replace 911, a county emergency notice, or a burn ban issued by the N.C. Forest Service. If you are unsure, call 919-499-9511. If you need help now, dial 911.

This page does not keep an archive of past incidents. News that the department chooses to publish lives on the news page.
